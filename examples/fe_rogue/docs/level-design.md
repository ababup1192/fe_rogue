# レベルデザイン指針（fe_rogue）

現行ダンジョン（f01〜f10）の難易度・成長バランスの設計意図をまとめる。
数値の実体は `resources/*.json` と `src/game/Combat.flix` にあり、本書は「なぜその値か」を残すためのもの。

## 全体方針

- **今のダンジョン（f01〜f10）は入門用**。今後ダンジョン種別を増やす前提で、現行は易しめに寄せている。
- 難易度は次の3レバーで調整する:
  1. **EXP獲得量** … 味方の育ちやすさ（全ダンジョン共通） → `Combat.flix`
  2. **敵ステータス / 編成** … 各フロアの手応え → `enemies.json` / `floors.json`
  3. **ドロップ** … 補給（武器・回復）の潤沢さ → `floors.json`

## 1. レベル・経験値の仕様

詳細ロジックは `LevelSystem.flix` / `Combat.flix`。

- EXP は 0〜99 で持ち、**100到達でレベルアップ**（余剰繰り越し、1攻撃で2レベルは無し）。
- 1攻撃の獲得 EXP は**レベル差ベース**:
  - 戦闘EXP `hitExp = max(1, (31 + 敵Lv − 自Lv) / classPower)`
  - 撃破EXP `killExp = max(0, classPower × (敵Lv − 自Lv) + 20)`（撃破時のみ加算）
- レベルアップ時、8ステータス各々で `乱数(0..99) < 成長率` なら +1。成長率は味方ごとに `units.json` の `growthRates`。敵は成長率を持たず、tier（_t1/_t2/_t3）で段階的に強い個体を用意する。

### EXP定数（`Combat.flix`）

| 定数 | 値 | 意味 |
|---|---|---|
| `classPower` | **2** | 除数兼係数。小さいほどEXP増。同レベル撃破=35（hit15+kill20）。**2〜3体撃破で1レベル**。<br>（旧3。難易度緩和で 3→2 に引き下げ） |
| `baseHitExp` | 31 | 戦闘EXPの基準値 |
| `killFlat` | 20 | 撃破EXPの固定加算 |

## 2. 敵ステータスと「レベル⇔ステータスの整合」

**設計原則: 敵tierのステータスは「同レベルの味方が成長率どおりに育っているはずの期待値」に合わせる。**
ズレると、レベル表記の割に異常に強い／弱い敵になり、難易度が読めなくなる。

味方の期待ステータス ≈ `基礎値 + (Lv−1) × 成長率/100`。これと敵tierを突き合わせる:

- **t1 ≒ Lv1 味方**、**t2 ≒ Lv3 味方** … おおむね整合（序盤は妥当）。
- **t3（Lv6相当）** … 旧データは同レベル味方より HP +4〜6・攻撃 +1.5〜2 と過剰だった。
  → 後半フロアが理不尽に硬く・痛くなっていた原因。**Lv6味方期待値付近まで HP・攻撃を引き下げ済み**。

### t3の調整実績（`enemies.json`）

| 敵 | HP | 攻撃 |
|---|---|---|
| fighter_t3 | 28→24 | 10→9 |
| barbarian_t3 | 36→31 | 13→11 |
| ranger_t3 | 26→22 | 10→9 |
| rogue_t3 | 22→19 | 7→6 |
| paladin_t3 | 34→29 | 8→7（守備11は据え置き＝壁役の個性） |
| cleric_t3 | 24→20 | 魔力 6→5 |

> 新tier・新ダンジョンの敵を足すときも、まず「想定対戦レベルの味方期待値」を出してから HP・攻撃を置くこと。

## 3. フロア編成（出現モンスター）

**Tier導入をなだらかにし、3段階のカーブにする。** 急に上位tierが混ざると一気に難しくなるため。

| フロア | 主tier |
|---|---|
| 1F〜3F | t1 のみ |
| 4F | t1主体（fighter_t2 を少量だけ混ぜる移行フロア） |
| 5F〜7F | t2 のみ |
| 8F | t2＋t3 の移行フロア |
| 9F〜10F | t3 主体 |

`monstersPerRoom` は深層ほど増やす（序盤 1〜2 → 終盤 4〜5）。

## 4. ドロップ（`floors.json` の `items` / `itemsPerRoom`）

**スターター武器（物理＝ブロンズ／魔法＝見習いの魔導書）は「初期武器」の位置づけ。** 各クラスの初期所持品であり、ダンジョン内では上位ランクへの乗り換えを促す（詳細は後述「武器設計」）。

- 各フロアの `items` は **iron 以上を主役**にし、bronze の出現比率は序盤フロアでも低めに抑える（3F以降は bronze を置かない）。
- **`vulnerary`（きずぐすり）を全フロアに weight 15 で投入**。補給を確保しつつ、回復過多にならない程度に。
  - ※ `vulnerary` は消耗品カタログの id。地面ドロップの id 解決は `ItemScene.lookupItem` が
    **weapons → staves → consumables** の順で引く。`floors.schema.json` の `items.to` は `weapons` のままなので、
    IDE上は consumable id が未解決参照に見えるが**実行時は問題なし**（スキーマrefはエディタ補完用メタ）。
- `itemsPerRoom` を全体的に増量（おおむね min2/max3〜min3/max5）。武器・回復が枯渇しにくいようにした。

`mithril_*`（ミスリル）は各フロアに 1% の超低確率で据え置き（ロマン枠）。

## 武器設計（`weapons.json`）

### 初期武器（スターター）の設計方針

**「弱いが長持ちする練習用」= 低攻撃・高耐久（durability 20）。** 各クラスの `initialInventory` に入る最弱ランクで、
ダンジョン内では上位ランクへの乗り換えを促す立ち位置。攻撃力は最低限に抑える代わり、序盤に武器が尽きないよう耐久を厚くする。

このスターター枠は**物理＝ブロンズ（銅）シリーズ**と、**魔法＝見習いの魔導書（`tome_apprentice`）**の2系統。両者を同じ設計で揃える:

| 武器 | 系統 | 攻撃 | 耐久 | 備考 |
|---|---|---|---|---|
| bronze_sword/lance/axe/bow | 物理 | 1〜3 | **20** | 攻撃 −1・耐久 12→20 に調整 |
| tome_apprentice（見習いの魔導書） | 魔法 | **3** | **20** | 攻撃 4→3・耐久 8→20 に調整。魔法版スターター |

> 新クラス・新系統を足すときも、初期武器は「攻撃最弱・耐久20」のスターター規格に合わせる。

### 物理武器ティアの目安

| ティア | 攻撃 | 耐久 | 位置づけ |
|---|---|---|---|
| bronze | 1〜3 | **20** | 初期武器（上記スターター枠） |
| iron | 5〜7 | 10 | 標準。序盤の主力乗り換え先 |
| steel | 8〜11 | 12 | 重いが高威力 |
| silver | 11〜14 | 5 | 高威力・低耐久の決戦兵装 |
| mithril | 14〜17 | 8 | レアドロップ |

### 魔法武器（魔導書）ティアの目安

| ティア | 攻撃 | 耐久 | 位置づけ |
|---|---|---|---|
| tome_apprentice（見習い） | 3 | **20** | 初期武器（魔法版スターター枠） |
