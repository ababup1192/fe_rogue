# platformer — ジャンプ手触りの検証台

エンジンがプラットフォーマーに耐えるかを最小構成で確かめる example。
背景なし・球体のプレイヤー。レベルはマリオ 1-1 規模の 208×30 テキストグリッド
（3328×480px・画面は 480×360 の引きの画角・カメラは横縦とも追従）。ジャンプの手触りは全部入り。

![地形の全景](gallery/screen_field.png)

## 遊び方

```
make run     # 起動（make debug で F8 注釈つき）
```

←→ で走り、Space でジャンプ。**長押しで高く、すぐ離すと低く**飛ぶ。
**Z（か左 Shift）で B ダッシュ** — マリオの P スピード式: 160 まではキビキビ加速し、
そこから最高速 280 へは 80px/s² でじわじわ伸びる（280 到達に約 330px・1.5 秒の助走）。
離しても勢いはなかなか死なない（160 への戻りも同じ緩さ）。空中の切り返しだけは別 —
進行方向と逆へ入力すると常に空中加速（500px/s²）で強く舵が切れる（スマブラの DI 風）。速度の段階は見た目に出る:
球体の色（黄 → 橙 → 白）、土埃の頻度と大きさ、最高速では残像が付く。
**↓+ジャンプ** で一方通行の床をすり抜けて降りる。
画面は 480×360 の引きの画角（横約 7 画面 × 縦 1.3 画面のレベル）で、カメラが不感帯つきで横にも縦にも追う
（縦の不感帯は広め = ジャンプごとに画面が揺れない。高い棚に登ると空が見える）。
崖（穴）に落ちると死亡: リスポーン地点へ戻され（カメラもスナップ）、HUD の deaths が増える。
敵は 3 種、まんじゅう型（平らな底 + 丸い上 + 目玉）で自機の球体と見分けやすい: 歩く敵（赤・足つき）と
パタパタ（桃・羽つき）は**踏むと倒せて**半ジャンプでバウンド、横から触れると死亡。
**トゲ（紫・上向きの棘つき）は踏んでも死ぬ**。

## レベル（マリオ 1-1 の文法・疾走感）

左から右へ 7 セクション、難度は緩やかに上がる。設計原理は**疾走感** — 全体を止まらずに
1 本の B ダッシュで走破できる。敵・段差・動く床は足を止める障害でなく滑走路の一部で、
**踏みバウンド（-320）は小ジャンプを兼ねる**: 歩く敵を踏むとそのまま次の穴を越えられる位置に
敵が置いてある（敵 = トランポリン）。歩く敵・パタパタ・フェリーの**位相（Motion の phase）**は
走破の台本が待たずに通れるよう調整済み。

1. 長い助走路（P スピードを 280 まで作る）
2. 低い段差 → 歩く敵（踏むと穴 1 を丸ごと越える）→ 一方通行の棚の塔（3 段・ボーナス高所）
3. 丘 — 緩い坂 → 台地 → 45° 坂 → 高台 → 緩い下り（下りの滑りで 280 超まで伸びる）
4. 浮き床の連続ジャンプ（下は地面 = 死なない練習）・地上にトゲ・抜けた先に**中間地点の旗**
   （越えると白 → 緑になり、以後の死亡はここへ戻る）
5. 長い助走路 → **P スピードゲートの大穴（128px）** — 280 のダッシュジャンプだけが渡れる
   （素の走りの最長 ≈110px）。上空に一方通行のボーナス床（高いルート）
6. 敵の織り込み — 歩く敵 2 体はダッシュの踏み 2 連鎖の間隔・パタパタ 2 体は位相調整で上空へ
7. フィナーレ — 大きめの穴（**フェリー**が位相調整済みで橋になる）→ 階段 → 高所の一方通行の
   棚 → 220px の大落下 → **ゴールの旗（x=3272）**

ゴールを越えるとクリア: ファンファーレ + HUD に CLEAR! が出て、**0.6 秒のタメ**のあと
**花火が 0.2 秒間隔で 10 発**、ゴール上空に 4 色（DB32）で開く。ゲームは止まらない（検証台なので）。

## 入っている手触り

| 要素 | 効き方 | パラメータ |
|---|---|---|
| 可変ジャンプ高 | 離した瞬間、上昇速度を 0.4 倍に削る | cutMult |
| コヨーテタイム | 崖を離れて 6/64 秒はまだ飛べる | coyoteTime |
| ジャンプバッファ | 着地の 8/64 秒前までの押下は着地時に飛ぶ | bufferTime |
| 非対称重力 | 下降 1.8 倍・頂点付近 0.5 倍（ふわり→ストン） | fallGravityMult / apexGravityMult |
| 慣性 | 空中の減速は地上の 1/12（走り勢いが残る） | airDecel / groundDecel |
| 空中制御 | 空中でも向きを変えられる（地上より弱い） | airAccel |
| B ダッシュ（P スピード） | 押している間、最高速 160 → 280。160 超の帯は 80px/s²（280 到達に約 330px）。離しても帯の中はゆっくりしか減速しない | dashMult / dashAccel |
| 坂 | 45° まで登れて接地が途切れない（下りは 6px の吸着）。登りは速度が斜面に沿い、静止は滑らない（静止摩擦）。下りの滑走はそのまま | — |

重力は「重力加速度」でなく**頂点の高さ（96px）と頂点までの時間（24 フレーム）**で指定する
（`初速 = -2h/t`・`重力 = 2h/t²`）。「もう少し高く」「もう少しキビキビ」を直接回せる。

## チューニングの回し方

1. `make run` で起動したまま `assets/parameters.json` を編集
2. **F1** を押す → その場で手触りが変わる（16 個全部が差し替わる）
3. 決まった値は `src/Jump.flix` の既定値へ昇格する（json はあくまで一時上書き・fail-open）

画面上部の HUD に速度・接地・コヨーテ/バッファ残の生値が常時出る。

## デバッグの装備

- **F8 注釈チケット**（`make debug`）: 時間停止 + ←→で最大 5 秒巻き戻し + ドラッグで矩形注釈。
  スクショ・赤枠・annotation.json に加え、**world.json**（運動学・タイマー・パラメータ全値・
  直近の出来事ログ・矩形に掛かる床の一覧）が同梱される。
- **リモートデバッグ**: `DEBUG=1 DEBUG_HTTP_PORT=7777 bin/flix run` で HTTP の lockstep 口が開く。
  `./debug/jump_probe.sh` がジャンプ曲線の再現台本（`hold space 24` → 頂点で vy≈0 →
  `until=sfx:land` で着地の瞬間に停止）。
- **ギャラリー**（`make bake` → `gallery/index.html`）: 満タンジャンプ・短押しタップ・
  浮き床走破に加え、看板の **full_clear_run**（スタート → ゴールの完全走破・踏み 3 連・
  フェリー・花火まで 1127 フレーム）。バイト決定的なので shasum 一致 = 挙動不変の証明。

## 見た目の約束事

- 一方通行の床は**薄い板**（上端 6px + 影線）で描く — 「薄い・下が透ける = すり抜けられる」の
  定番記号。当たり判定の上面と見た目の上面は一致する。動く床は厚い一枚板のまま（厚い = 硬い）。
- 地面の草は**空が見える上面だけ**に生える。積まれた段は土のまま（縞にならない）。
- レベル端の落下防止はグリッドの柱でなく**画面外の見えない壁**（id 198/199）が担う。

## テスト

```
make test    # 97 本・数秒
```

ジャンプ曲線（頂点の高さ・24 フレーム目の頂点・落下 21f < 上昇 23f）、コヨーテ／バッファの
成立と失効、慣性と摩擦（厳密値）、B ダッシュ＝P スピード（二帯加速・280 ちょうど到達・
勢いの持続・空中の切り返しは airAccel／進行方向の上積みは P 帯）、崖死亡とリスポーン、
ダッシュ崖越えの成立（P スピード済み preset から）／素の走りでの失敗（ゲート）、着地・頭ぶつけ・崖離れ、動く床と一方通行、
坂（登り・下りの吸着・接地しきい値・静止摩擦・登りの逆滑り回帰）、
敵 3 種（触れたら死・踏みバウンド -320・トゲ・骸すり抜け・物理不干渉・同フレームは死亡が勝つ）、
レベルのグリッドパーサ（run 融合・敵とゴール・中間地点の抽出）、カメラの追従・クランプ・
死亡スナップ（横縦とも）、P スピードゲート（ダッシュは渡れる／素の走りは落ちる）、
中間地点（1 回だけ発動・死亡はそこへ戻る）、クリアと花火（タメ 0.6 秒 → ちょうど 10 発）、
レベル完全走破の台本（死亡 0・踏み 3 体・クリアまで）、world.json の中身、
演出の粒（ジャンプ噴射の発生・ダッシュ土埃の cadence・寿命切れ）、
を具体値で pin。
dt = 1/64（2進小数）とタイマー既定値（1/64 の倍数）のおかげで、pin の大半は誤差なしの厳密比較。
