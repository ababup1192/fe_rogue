# feature_lab ローカルメモ

## この画面の画風（光マップデモ: ランタン 2 個と壁の影）

- 題材: 夜警の見回り（石壁の間に置いた 2 つのランタン）
- 色 3 つ: 下地 = 夜の紺 #1a1826（環境光そのまま）/ 主役 = ランタンの橙（light.json の色）/
  差し色 = 月白の白丸 #ffffff
- やらないこと: 輪郭線を引かない（暗がりの分離は光と影だけで作る）

絵の下限（4 性質の担い手）:

- 面に階調か質感: 光マップの放射グラデ（Render.lightAt の Add）が床に階調を作る
- 主役の分離: 橙の光だまり 2 つが紺の闇から浮く
- 層: 奥（暗い床＋目印）/ 主役（壁と光だまり）/ 手前（光マップの Multiply 覆い）
- 時間: ランタンが動いた連番 2 枚で影の向きが回る

## この画面の画風（tex 場デモ: TexDemo.flix）

- 題材: 夕暮れの湖岸（水鏡と陽炎）
- 色 3 つ: 下地 = 夜の群青 #1a1c2c / 主役 = 茜の夕日 #f2a65a / 差し色 = 薄荷の水明かり #7fe8d8
- やらないこと: 輪郭線を引かない

絵の下限（4 性質の担い手）:

- 面に階調か質感: vgrad の空 + Gradient グレーディング（tex_grade）
- 主役の分離: 茜の夕日と反射帯が群青の地から浮く
- 層: 空 / 丘 2 層 / 湖面 の 3 層
- 時間: tex_haze の陽炎ゆらぎ（完全ループ GIF）
