# 用語集 — UI の言葉と内部語の対応

UI に出す言葉と文の決め方:

- **効果語だけ**: それをするとどうなるかが、聞いてすぐ分かる言葉を使う。説明が要る言葉は使わない
- 内部語(bake / bless / golden / promote / family / entityId 等)はコード・ログ・make の世界のもの。UI に出さない
- ひらがなを多用しない。実在ゲーム名を説明に使わない
- 一つの概念に言い方は一つ。ここに無い言い換えを増やさない
- 案内の文は、して欲しい**行動**を言う(機能や在庫の説明にしない)
- 行き止まりを作らない — 案内カードには必ず押せる次の一歩を添える
- 案内は普通の説明文で書く。セリフ調・体言止めの演出をしない

| UI の言葉 | 意味 | 内部語・実体 |
|---|---|---|
| ジャンル | 新しいゲームの入口 9 枚。内訳は「含む: …」の行が語る | family(/genesis/families) |
| テンプレート | 動く最小ゲーム。選ぶ=複製、ゼロ抽選 | templates/(starter) |
| プロンプト | AI に貼る依頼文。公式プロンプト=骨格と完了条件を焼き込んだ下書き | /prompt/* |
| エッセンス | 世界の匂いの一行。遊びにも素材の方向性にも流れる | — |
| 候補 | 採用前の試作 | atelier/*.json |
| 素材スロット | assets/ のパス=差し替えの受け口。席は動かず、中身が替わる | slot |
| これを使う / 切り替える | 候補をゲームに入れる操作 | promote(swap) |
| 採用 | 切り替えの結果。候補の中身が素材スロットへ移り、候補の身分が終わる | promote(候補ファイル削除) |
| バージョン(v1, v2…) | 採用のたび積まれる過去の中身。「↩ v3 に戻す」 | atelier/archive/<base>.vN.<kind>.json |
| アーカイブ(する) | 使わない候補と過去バージョンの置き場(へ送る)。何も捨てない | atelier/archive/ |
| 候補に戻す | アーカイブから候補の列へ | /atelier/restore |
| 候補選び / 調整 / アーカイブ | アトリエの 3 モード(選ぶ / role:tuning をいじる / とっておく) | picks / storehouse / archive |
| 手直し | 素材をその場で直すポップアップ(グリッド・カーブ・音ツマミ)。道具が素材のところへ来る | (Phase 4) |
| 次のやること | 状態検知から次の一歩を 1 枚だけ出す誘導 | journey(/journey/state) |
| 見た目が変わりました | 自動検査の知らせ。前と今を見比べられる(見なくてもよい) | /journey/changes |
| 前 / 今 | 見比べの 2 枚のラベル | golden/archive/<scene>.vN.png / golden/<scene> |
| 選んだ組み合わせで試す | 複数の候補を、何も書き換えずに組み合わせて走らせて比べる | (提案) |
| 昇格 | 良いテンプレートが templates/ 入りして、ジャンルが公式テンプレートつきになる | — |
| アレンジ | 生まれたゲームのパラメータを変えて、自分のものにしていく行為(場所は調整) | — |
| パラメータ | 調整で変えられる値(速さ・色・文言など) | Doc のフィールド |
