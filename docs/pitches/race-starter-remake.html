最後のコーナーまで
勝敗が判らないレースへ

今のレーステンプレは「綺麗に走れるが、何も起きない」夜道だった。舞台を真夏の海岸ハイウェイへ引っ越し、急カーブをドリフトで攻めさせ、敵に意思を、順位に揺れを入れて、ハラハラドキドキする追い抜き合戦へ作り直す企画書。

1. 今のレースの何がつまらないか

骨格（周回・追い抜き加点・はみ出し減速・Doc 化・テスト・golden）はよく出来ている。つまらなさの原因は 4 つに絞れる。

  • コースが実質まっすぐ。文字格子は少し蛇行しているが、画面はただ縦に流れる夜道で、ハンドルを切る理由がほとんどない。コーナーこそレースの本体なのに、それが無い。
  • ライバルが「動く背景」でしかない。2 台とも固定レーンを等速で走るだけ（moveRivals は progress の足し算のみ）。横に動かない、こちらを見ていない、当たりもしない。
  • 順位が序盤で確定する。自機 120 > ライバル 96 / 108 で、普通に走れば必ず抜けて必ず 1 位。抜いた後は最後まで一人旅。
  • 失うものがない。敗北なし・クラッシュなし。はみ出しても少し遅くなるだけで、心拍数が上がる瞬間が 1 度もない。

2. レースゲームの面白さの分解

名作がやっていることを 5 つに分解する。以降の設計はすべてこの 5 点に紐づける。

性質中身お手本
コーナーが主役直線は息継ぎ、勝負はカーブで決まる。減速して安全に曲がるか、ドリフトで速度を殺さず攻めるか、毎コーナーが選択になるリッジレーサー、頭文字D、OutRun の連続カーブ
接戦の維持敵が常に視界にいる。離されても追いつけるし、引き離しても追ってくるマリオカートのラバーバンド、F-Zero のライバル群
リスクとリターンの往復速く走る手段が、必ず危険と抱き合わせになっている。安全に走ると遅いドリフト、敵の真後ろのスリップストリーム

4. メカニクス 5 本柱

柱ごとに「仕組み / 数値の初期案 / Doc へ出す値 / テストで守ること」を書く。数値はすべて Doc に出すので、実装後にエディタで走らせながら詰め直す前提の初期値。

柱 1急カーブとドリフト — 操作の核。ここが今回の本丸

コースをうねらせる: 文字格子はそのまま、路面の中心列を行ごとに大きくずらして S 字・複合カーブ・ヘアピン級の切り返しを作る。画面は縦スクロールのまま、描画だけを OutRun 式に曲げる — 各行の横ずれを手前から奥へ積み上げ、道が画面の中で折れ込んで見える投影にする（ルールは格子のまま、写像は View の 1 関数）。まっすぐな道の絵には二度としない。

グリップの限界: カーブの急さ（行ごとの中心のずれ量から導出）と速度に応じて、車がアウトへ膨らむ。速いまま急カーブへ入ると、ハンドルだけでは曲がり切れず縁石の外へ押し出される — 減速して曲がるのが基本。

ドリフト: X を押しながら曲がると後輪が流れ、減速せずに深い舵角で曲がれる。ドリフト中はニトロゲージが貯まり続ける（貯まる速さは柱 3 の中で最大）。ただし車体は横へ流れ続けるので、切り返しが遅れれば縁石へ突っ込む。「毎コーナーで、安全な減速か、ゲージの貯まるドリフトか」を選ばせるのがこの柱の仕事。

Doc キー初期値意味
gripSpeed90これ以下の速度なら膨らまずに曲がれる
curvePush1.6カーブの急さ×超過速度に掛かる横押しの強さ
driftTurnBoost1.7ドリフト中の舵角倍率
driftSlide45ドリフト中に外へ流れ続ける速さ
brakeSlow0.6ブレーキ（↓）中の速度倍率

テスト: カーブ量の導出（格子の中心ずれ→急さ）/ 速度超過時だけアウトへ押される / ドリフト中は押し出しが打ち消される / ブレーキの減速。曲げて描く投影はテストしない（golden の仕事）。

柱 2スリップストリーム + ラバーバンド AI — 接戦の維持

スリップストリーム: 前走車の真後ろの帯（幅 24px × 長さ 48px 程度）に入ると前進速度が 1.35 倍。帯に入っている間はニトロゲージも貯まる。

ラバーバンド AI: ライバルの速度を自機との距離差で補正する。離されるほど速く（最大 +22%）、引き離すほど遅く（最大 −15%）。ライバルはコーナーで減速し、レコードラインへ寄る（コースの中心へ滑らかに戻る決定的ルール。前が詰まったら横へずれる。乱数なし）。台数は 2 → 3 台に増やし、順位の揺れ幅を作る。コーナーが下手な敵・直線で速い敵、と性格を rows で持たせる。

Doc キー初期値意味
slipBoost1.35スリップ帯内の速度倍率
slipRange48帯の長さ（px）
rubberRange400補正が最大になる距離差
rubberCatchUp0.22離された時の加速上限
rubberSlowDown0.15先行時の減速上限

テスト: 帯の内外でスリップ判定が切り替わる / 距離差に応じて補正の符号が変わる / コーナーで AI が減速する。

柱 3ニトロ / ブーストゲージ — リスクとリターンの往復

危険な走りだけがゲージを貯める: ドリフト維持（毎秒・最速）、スリップ帯の維持（毎秒）、障害物・ライバルすれすれ（1 回ごと）。Z で発動し、一定時間だけ爆発的に加速する。ただし発動中は操舵が半分に重くなるうえグリップ限界はそのまま — 直線で撃てば安全に速く、コーナー明けに撃てば博打で最速。

Doc キー初期値意味
nitroChargeDrift0.35ドリフト 1 秒あたりの加算（満タン=1.0）
nitroChargeSlip0.20スリップ維持 1 秒あたりの加算
nitroChargeNearMiss0.25すれすれ 1 回の加算
nitroBoost1.8発動中の速度倍率
nitroDuration1.2発動時間（秒）
nitroSteerPenalty0.5発動中の操舵倍率

テスト: ゲージの収支（3 経路で貯まる・上限 1.0・発動で消費）/ 未満タンでは発動しない / 発動中の速度と操舵の倍率。

柱 4障害物とクラッシュ、敗北 — 失うものを作る

コース格子に障害マス（X = コーン列・落下物）を置く。障害物・ライバル・縁石の外の壁に当たるとスピン: 約 1 秒間、操作不能でくるくる回りながら大きく減速し、ニトロゲージも半減する。ドリフトの失敗がそのままクラッシュに繋がる。

敗北条件: 完走時に最下位（4 位）なら LOSE。ラバーバンドで敵は常に近くにいるので、「スピン 2 回で負けが見える」緊張感が出る。プレイヤーが詰まない原則は守る: スピンしても必ず復帰し、レースは最後まで走れる。

Doc キー初期値意味
spinDuration1.0スピン時間（秒）
spinSlow0.3スピン中の速度倍率
spinNitroLoss0.5スピン時に失うゲージ割合
nearMissDist10「すれすれ」と判定する距離（px）

テスト: 障害マス・壁との接触でスピン状態に入る / スピン中は操作が効かない / 時間経過で復帰する / 最下位ゴールで LOSE、それ以外は WIN。当たりの有無はルールなのでテスト対象、スピンの回転演出はテストしない。

柱 5アイテム — 最終ラップの逆転劇

コース格子にアイテムマス（I = 光る「?」）を固定配置する。効果は取った瞬間の順位で決める: 1 位なら小さく（スコアボーナス）、2 位ならニトロゲージ +30%、3〜4 位なら即時の大ブースト。乱数はゼロ — マリオカートから「下位ほど強い」という逆転補正だけを頂き、運の要素は入れない。テンプレとして決定的（テスト・bake が安定）なまま、最終ラップの逆転を仕組みで保証する。

5. コース設計 — 直線は息継ぎでしかない

1 周をリズムで組む: スタート直線（スリップ勝負）→ S 字（ドリフト練習）→ アイテム直線 → 複合カーブ（障害物入り）→ 最終の急な切り返し（逆転ポイント）。急カーブの手前にはシェブロン看板を必ず置き、初見でも「来るぞ」が判るようにする。

6. 絵作り — 真夏の昼、誤魔化しの利かない日向で

絵の下限 4 性質（面の階調・主役の分離・層・時間）は維持したまま、夜と霧に頼らない昼の絵へ作り替える。昼はごまかしが利かない — その分、決めるべき道具をはっきり決める。

  • 空と海が背景の主役: コバルト→淡青の空グラデ・入道雲・きらめく海（白い短線の明滅）・太陽のハロ。地平線で空と海が切り替わるだけで、画面の上半分に「夏」が入る。
  • 影が絵を地面に貼り付ける: 車の落ち影・ヤシの影・看板の影。昼の絵の説得力は影が 8 割。すべての置き物に楕円 1 枚の落ち影を必ず敷く（主役の分離もこれが受け持つ）。
  • マシンは矩形 1 枚をやめてパーツ構成にする: ボディ（先細りのカプセル）+ キャノピー + ルーフ + リアウィング + 4 輪 + センターストライプ + 日差しのハイライト + 落ち影。polygon 数枚で組める分量に抑えつつ、拡大しても「車」に見える形にする（上のモックの車がそのまま実装仕様）。
  • OutRun 式の曲がる投影: 各行の横ずれを手前から奥へ積み上げ、道が画面の中で折れ込む。行の高さも遠くほど詰めて収束。カーブ中はカメラをイン側へ寄せ、視線をコーナーの先へ。
  • コーナーの道具立て: 外側に赤白の縁石・黄色いシェブロン看板・ヤシの木・スポンサー看板。景色がカーブに沿って流れて初めて「曲がっている」が見える。
  • ドリフト演出: 車体を進行方向より内へ傾け（turns 回転）、後輪から黒いタイヤ痕 2 本・白い煙（昼だからこそ映える）・橙の火花。閉形式 (spec, seed, i, t) の純関数で導出し、保存する状態は増やさない。
  • ニトロ演出: 橙→白の炎・赤い残像 2〜3 枚・白い速度線の倍増・画面端の熱の縁・路面スクロール倍速。
  • スピン演出: 1 秒 2 回転 + 火花の飛散 + 接触の瞬間 2 フレームの白フラッシュ。
  • 接戦の演出: ライバルが近い間だけ相手の輪郭に薄い縁光と、自機 HUD の順位を揺らす。危険の近さが色と揺れで判る。

画風宣言の改訂案（AGENTS.local.md の形式のまま）:
「真夏の海岸ハイウェイ。空は青く、海は光り、路面は白く灼けている。速さは流れる景色とタイヤ痕で、危険は膨らむ白煙で見せる」
色は 3 つ: コバルトの空 / 灼けたアスファルト / 縁石の赤。
やらないこと: 暗がりや霧で誤魔化さない（全部日向で見せる。分離は影の仕事）。
※ 同じ「昼」でも rpg テンプレ（陽だまりの城下町・ドット絵）とは別画風 — こちらは高彩度・ベクタ形状のレーシング。テンプレどうしで画風を揃えない方針は守る。

7. Doc 設計

  • race.rules.json: 上の表の約 20 キーを追加。スカラー総数 30 個の分割ラインを超えるので、最初から 2 Doc に割る: race.rules.json（走行・ドリフト・ニトロ・クラッシュ・アイテム = 手触り）と race.rivals.json（ラバーバンド + ライバル 3 台の rows = 敵の性格）。「いつ読み直したいか」が違う（手触り調整 vs 難易度調整）ので関心も分かれる。
  • race.course.json: 文字の語彙を拡張 — # 路面 / . 草 / I アイテム / X 障害物。カーブの急さは中心列のずれから導出（導出できる値は Doc に持たない）。判定は今まで通り CourseDoc の 1 か所に集める。
  • race.theme.json: 全色を昼へ差し替え — 空 2 色・海・草・路面・縁石の赤・シェブロンの黄・マシン 4 色（自機の赤 + ライバル青/黄/緑）・炎・煙。
  • すべて sections 方言のスキーマ・fail-open・保存即反映（watchFile）は現状のまま。

8. テスト・bake 方針

テストするのはルールだけ（カーブ急さの導出・グリップ超過の押し出し・ドリフトの打ち消し・ラバーバンド補正・ゲージ収支・スピン遷移・順位と勝敗・アイテム効果・course 文字判定）。期待値は RulesDoc.defaults() から導く。曲げる投影・タイヤ痕・煙はテストしない — golden と目視の仕事。Doc 橋渡しは 1 Doc 3 本以内を維持。

bake の 4 場面を差し替える: タイトル / ドリフト（急カーブ・タイヤ痕・煙）/ ニトロ発動（残像と炎）/ クラッシュ（スピンと白フラッシュ明け）。ハラハラの画がそのままジャンル札のサムネになる。golden/title.png は必ず維持する。

10. この企画で race-starter は何のお手本になるか

今のテンプレは「Doc 化とテストのお手本」だった。作り直し後は加えて、「格子コースのまま道を曲げて見せる投影」「昼の絵を影とパーツ構成で成立させる書き方」「リスクとリターンをルールで組む書き方（ドリフト＝危険なほど強い）」「乱数なしで逆転劇を作る書き方」のお手本になる。凝った物理も乱数もなしに、決定的なルールの噛み合わせだけでハラハラドキドキは作れる — それをジャンルの顔として見せる。
