# engine 0.32.0 → 0.33.0 の手当て

自動生成の一覧は [0.33.0.auto.md](0.33.0.auto.md)。ここには、そこに載る 2 件の直し方を書く。

## なぜ変わったか

`Drawable` と `BoxStyle` はレコードだった。Flix のレコードは JVM 上で
「1 フィールド = 1 オブジェクト」の連結リストになるので、毎フレーム数千個作ると
その数だけオブジェクトが生まれ、`#field` を読むたびに連結を辿ることになる。
両方ともフラットな enum に変えた（`Drawable` 1 個 906B → 748B、箱 1 個 2375B → 2166B、
物量を出す場面のフレーム時間が 3〜4 割短縮）。

位置引数が 20 個（`BoxStyle` は 18 個）並ぶので、**構築と分解を呼び側に書かせない**。
入口は下の 2 つだけで、並びに触るのは `DrawCmd` の中だけになっている。

## 1. Drawable を組んでいた所

```flix
// 前（レコードリテラル）
let d = { texture = "hero", position = pos, scale = size, rotation = 0.0,
          color = white, alpha = 1.0, centered = true, uvOffset = uv0, uvScale = uv1,
          zIndex = 10, style = None, clip = None, blend = BlendMode.Alpha, mask = Nil };

// 後A: 名前付きで安全に組む（テスト・めったに呼ばれない構築）
let d = DrawCmd.make({ texture = "hero", position = pos, scale = size, rotation = 0.0,
                       color = white, alpha = 1.0, centered = true, uvOffset = uv0, uvScale = uv1,
                       zIndex = 10, style = None, clip = None, blend = BlendMode.Alpha, mask = Nil });

// 後B: 毎フレーム大量に通る変換（spec レコードを作らないぶん速い）
let d = DrawCmd.fromParts("hero", pos, size, 0.0, white, 1.0, true, uv0, uv1, 10,
                          None, None, BlendMode.Alpha, Nil);
```

`make` は前のレコードをそのまま渡せる。**まず `make` に置き換えて動かし、
毎フレーム通る所だけ `fromParts` へ**。

## 2. Drawable を読んでいた所

```flix
// 前
let z = d#zIndex;
let p = d#position;

// 後: 1 つだけ読むならアクセサ
let z = DrawCmd.zIndexOf(d);
let p = DrawCmd.positionOf(d);

// 後: 何個も読むなら match で一度に受ける（毎フレーム通る所はこちら）
let DrawCmd.Drawable.Drawable(tex, px, py, sx, sy, rot,
                              cr, cg, cb, a, cen,
                              uox, uoy, usx, usy, z,
                              style, clip, blend, mask) = d;
```

分解の変数名はこの並び・この改行の位置で書く（`DrawCmd` の中も全部そろえてある。
隣どうしの `Float64` の取り違えはコンパイルが通ってしまうので、縦に見比べられる形にしておく）。

## 3. 一部だけ差し替えていた所

```flix
// 前
let d2 = { zIndex = 20 | d };

// 後: よく使う組み合わせは with* が用意してある
let d2 = DrawCmd.withTintAndZIndex(color, 20, d);   // 色と重なり順
let d2 = DrawCmd.withScale(scale, d);
let d2 = DrawCmd.withClip(clip, d);
let d2 = DrawCmd.withPositionAndRotation(pos, rot, d);
let d2 = DrawCmd.withUv(uvOffset, uvScale, d);

// 後: 当てはまる with* が無ければ spec に戻して組み直す（毎フレーム通らない所向け）
let d2 = DrawCmd.make({ zIndex = 20 | DrawCmd.toSpec(d) });
```

## 4. BoxStyle も同じ形

```flix
// 前
let st = { cornerRadius = 4.0, borderWidth = 1.0, borderColor = c, ... };
let r  = st#cornerRadius;

// 後
let st = DrawCmd.makeStyle({ cornerRadius = 4.0, borderWidth = 1.0, borderColor = c, ... });
let st = DrawCmd.defaultStyle |> DrawCmd.withCornerRadius(4.0) |> DrawCmd.withBorder(1.0, c, 1.0);
let r  = DrawCmd.styleToSpec(st)#cornerRadius;     // 1 個読むだけならこれで足りる
```

`withCornerRadius` / `withBorder` / `withStripe` / `withChecker` があるので、
`defaultStyle` から足していく書き方が一番短い。

## 直し方の手順

1. `flix check` を打つ。レコードとして触っている所が全部エラーになる（黙って通ることはない）
2. エラーの出た順に、構築は `make` / 読みはアクセサ / 差し替えは `with*` へ置き換える
3. 緑になったら `make render-all` と `make reference-check` で絵が変わっていないことを確かめる
