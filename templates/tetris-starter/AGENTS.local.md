# このゲーム固有の設計原則

落ち物パズル（テトリス）のテンプレート。原始的なテトリスに、読んで学べる最小限の
「今どき」を足した骨格 — NEXT（次のミノ 1 個）・回転で設置面にねばる猶予（lock delay）・
簡易ウォールキック・着地予測（ゴースト）・ライン消しの控えめな閃光演出。

- **規則はコード、数値と色は Doc**（エッセンス）。落ちる・寄る・回る・接地でねばる・
  そろって消える・涌く の規則は `src/World.flix`（純粋）にある。JSON に if 文を書き始めたら
  境界を越えた合図。調整する数値は `assets/tetris.rules.json`、色は `assets/tetris.theme.json`。
- **形の知識は Pieces に隔離**: 「どの向きのときどの 4 マスか」と回転・キック候補だけを
  `src/Pieces.flix` に集め、World を「規則」に集中させる。SRS 完全でなくてよい（原始的）。
- **決定的な擬似乱数（7-bag）**: 涌き順は純粋な LCG（seed から）で決める。bake も遊びも
  同じ seed から同じ並びで再現できる。実時間・グローバル乱数に依存しない。
- **設置面ねばりはルール**: 接地後 `lockDelay` の猶予があり、移動/回転の成功で猶予が 0 に戻る
  （`maxLockResets` が無限延命の天井）。ここはテストする（演出ではなくルール）。
- **足さないもの**: ホールド・T スピン判定・レベル/落下加速の自動上昇・スコアの複雑な倍率・
  セーブ・対戦。この骨格に亜種の決め打ちを足さない（足すなら別テンプレ）。
- **プレイヤーは詰まない・壊れない**: 壊れた Doc でも fail-open で必ず起動し、GAME OVER から
  Space で必ず仕切り直せる。View も盤が空・Doc 既定で必ず何か描く。
- 描画はエンジンの `Render`（`boxAt`/`box`/`textTinted`/`fade`/`glowAt`）を使い、
  幾何・文字折り・パーティクルを自前で書かない。ライン消しの光球は `Render.glowAt`
  （閉形式で安全）に任せ、粒子系を手書きしない。

## テストの当てどころ（ルールだけ）

- 衝突（壁・床・既存セル）・回転で形が変わる・壁際でウォールキックが入る。
- ライン検出（1 行・複数行）と実消去で上の行が詰まる。
- 接地/lock（`lockDelay` 到達で固定・移動/回転で lockTimer が 0 に戻る・`maxLockResets` で強制固定）。
- 涌き衝突 → GAME OVER・hardDrop がスタックの上に載る・スコアは `RulesDoc.scoreFor`（Doc 参照）。
- 閃光・光球・ゴーストの見た目はテストしない（golden / 目視の担当）。
