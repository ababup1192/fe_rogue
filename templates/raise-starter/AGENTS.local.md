# このゲーム固有の設計原則

育成シミュレーションのテンプレート。ターン制・メニュー選択・Doc 主体の骨格 — 毎日ひとつ行動を
選ぶと数値（パラメータ）が育ち、ときどきイベントが起き、日数を使い切ると発表会で結末が決まる。
リアルタイム系（shooter / race）とは別系統の「選ぶだけ」の入力と、表（rows）主体の Doc を教科書にする。

- **規則はコード、表・数値・色は Doc**（エッセンス）。伸ばす・確率でイベントを抽選する・
  結末をしきい値で選ぶ の規則は `src/World.flix`（純粋）にある。JSON に if 文を書き始めたら
  境界を越えた合図。調整する数値は `assets/raise.rules.json`、色は `assets/raise.theme.json`、
  行動・イベント・結末の一覧と文言は `assets/raise.plan.json`。
- **行動・イベント・結末は表（rows）**: `PlanDoc` が「オブジェクトの配列」を 1 行ずつ拾う
  （`JsonCodec.decodeList`）。行を足せば選択肢や結末が増える。文言（行動名・イベント文・結末文）は
  すべて Doc に置き、コードに直書きしない（UI の構造ラベル = DAY / LEFT / RESULT のみコード可）。
- **パラメータは 3 つの数の組（`PlanDoc.Stats`）**: 行動の伸び・イベントの増減・いまの育ち、
  どれも同じ `Stats` 型で表す。足し算は `addStats`、合計は `total` に 1 か所ずつ名付ける
  （同じ計算をあちこちに書かない）。上限（statCap）で頭打ちにするのは `World.capStats`。
- **入力は「選ぶだけ」= すべて justPressed**: ターン制なので押しっぱなしの連続入力は無い。
  ↑↓（←→でも可）でカーソルを 1 つ動かし、Space/Enter で 1 ターン進める。カーソルが動くのは
  Day のときだけ（`World.moveCursor` が Day 以外で無視する）。決定の意味は場面依存（`World.confirm`）。
- **イベント抽選は決定的**: 乱数は seed から始まる LCG（`World.nextRand`）を World の `rng` に持たせ、
  引くたびに状態を進める（同じ seed なら同じ運び = 再現できる・テストできる）。まず eventChance で
  「起きるか」を決め、起きるなら weight の重み付き抽選（`pickWeighted`）で 1 つ選ぶ。
- **結末はしきい値**: 合計値（`total`）を threshold の大きい順に見て最初に届いた結末を選ぶ
  （`PlanDoc.endingFor`）。一番小さいしきい値を 0 にして必ずどれかに当たるようにする（詰まない）。
- **演出は控えめに凝る**: 伸びた合図は一番大きく伸びた棒の右端にきらめき（`Render.glowAt`・
  閉形式で安全）を 1 つ。粒子系は自前で書かない。棒・文字・幕はエンジンの `Render` / `TextDraw` に任せる。
- **足さないもの**: 複数キャラ・所持金や在庫・複雑な依存イベント（前提フラグの連鎖）・
  戦闘やミニゲーム・セーブ。この骨格に亜種の決め打ちを足さない（足すなら別テンプレ）。
- **プレイヤーは死なない・詰まない・壊れない**: 壊れた Doc でも fail-open で必ず起動し、
  行動が空・結末が空でも既定へ倒れて進める。Result から Space で必ず Title へ戻れる。

## テストの当てどころ（ルール・進行・収支だけ）

- 場面の決定（Title→Day で育ち 0 リセット・Result→Title で仕切り直し）。
- メニューのカーソル（端で回り込む・Day 以外では動かない = クリック当たりの有無に相当するルール）。
- 行動で数値が育つ（伸び幅は Doc の行動 `PlanDoc.actionAt` から導く）・上限（statCap）で頭打ち。
- 日の進行（Reveal を送ると day++・dayCount ぶん決め切ったら Result）。
- 結末の選び方（合計が一番上のしきい値以上なら一番上・合計 0 なら一番下）。しきい値は Doc から導く。
- 育ちの合計（3 パラメータの和）が結末の判定に使う値であること。
- きらめき・棒の見た目・カーソルの帯・文字の位置はテストしない（golden / 目視の担当）。
- イベント抽選の「見た目のランダムさ」はテストしない。抽選の骨格（weight 0 は出ない・
  合計 0 なら None）はルールなので、必要なら World の抽選部品を直接当てる。
