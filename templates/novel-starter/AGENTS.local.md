# このゲーム固有の設計原則

ノベル・推理のテンプレート「消えた絵」。雨の夜の洋館、停電した書斎から一枚の絵が消えた。
主人公は招かれた時計職人（観察が癖）。

- **文章・分岐・結末は全部 Doc の rows**（assets/novel.story.json）。台本を書き換えれば
  別の事件になる。進め方の規則（拍の送り・分岐・結末で表紙へ戻る）はコード（World）。
- **疑う相手を選ぶたび、館の照明がひとつ消える**（エッセンス）。suspect の選択肢だけが
  灯りを消す。灯りは台本の lamps より多くは消えず、もう一度はじめると全部つき直る。
- **操作は「選ぶだけ」**: ↑↓（カーソル）と決定（クリック / Z / Enter / Space）。
  それ以外の操作を足さない。
- **プレイヤーは死なない・詰まない**: どの結末も読み終われば表紙へ戻る。壊れた台本でも
  fail-open で必ず起動し、必ず表紙に帰れる。
- 会話窓・文字送り・選択肢はエンジンの UiDialog / UiTypewriter / RichText / UiSlots /
  UiMenu を使う。自前の文字折りやメニューを書かない。
