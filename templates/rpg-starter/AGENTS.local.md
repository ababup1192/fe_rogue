# このゲーム固有の設計原則

RPG・アドベンチャー（見下ろし）のテンプレート「陽だまりの城下町」。高い青空の下、
石畳の通りと水路のある城下町。主人公は薬草を届けに来た行商の子。薬草を届けるたび、
広場の灯りがひとつずつ点いていく。

- **鍵はぜんぶ、誰かとの約束でできている**（エッセンス）。物の鍵は出てこない —
  扉（木戸）は door の promise の住人に頼まれた数の薬草を持って話しかけると開く。
  鍵アイテム・インベントリを足さない。
- **盤面のデータは全部 MapDoc**（assets/rpg.map.json）: タイルの rows・住人と 1 行・
  扉と約束・薬草と灯りの配置・goal。歩ける/ぶつかる/開く/クリアの規則はコード（World）。
- **操作は「歩く」と「話す（決定）」だけ**: ←→↑↓（WASD 可）と Z / Enter / Space。
  それ以外の操作を足さない。
- **戦いは 1 対 1 のコマンド式・1 種類だけ**（assets/rpg.battle.json）。歩数で出会い、
  「たたかう / にげる」を選ぶ。**乱数は持ち込まない** — 何歩めで出会うかも、一撃の重さも
  Doc の数から決まる（決定的なので描き出した絵もテストの期待値も揺れない。難しさの調整は
  Doc 側の数で足りる）。**レベル・経験値・仲間・呪文・道具・複数の魔物は足さない** —
  亜種の決め打ちになる。
- **セーブ・複数マップは持ち込まない**。
- **プレイヤーは死なない・詰まない**: goal は置いた薬草より多くを求めない（World.goalOf が
  clamp）。壊れた Doc でも fail-open で必ず起動し、クリアから表紙へ必ず帰れる。
- **倒れても詰まない**: 体力が尽きたら入口へ戻って体力が満ちる（ゲームオーバーで
  進行を失わせない）。「にげる」は必ず成功する。
- 盤のマス勘定は Grid / Dir4、キーは InputMap、ふきだしの状態と文字送りは
  UiDialog / UiTypewriter / RichText を使う。自前のタイル座標計算・文字折りを書かない。
- 薬草を拾うたび、広場の灯りがひとつ点く（lampsLit は picked からの導出。演出であって
  ルールではないのでテストしない）。

## この画面の画風

**「晴れた昼の城下町」。** 高い青空の下、石畳と水路が光り、家々の漆喰がまぶしい。
他のテンプレ群（夜のネオン・紙の刷り物・霧の夕暮れ・雨の夜）と揃えない — 高彩度の昼を
このテンプレが受け持つ。

- 色は 3 つ: 芝の緑 / 漆喰の白 / 屋根の赤茶。
- やらないこと: 輪郭に純黒を使わない（影も彩度のある濃色にする — 昼の影は色が残る）。
- ドット絵は 16×16・等倍（タイル 16px にぴったり収まる）。
- 意味色キー（grass / pave / water / plaster …）の実色は `ThemeDoc.resolver` が
  基準色（field / wall / cloth / paper）から導く。色票（rpg.theme.json）に足すのは
  「そこから導けない色」だけ。キーを足したら `make palette` で写しを作り直す。
