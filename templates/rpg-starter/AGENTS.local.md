# このゲーム固有の設計原則

RPG・アドベンチャー（見下ろし）のテンプレート「霧の里」。霧の出た段々畑の里、夕暮れ、
灯りがひとつずつ点いていく。主人公は薬草を届けに来た行商の子。

- **鍵はぜんぶ、誰かとの約束でできている**（エッセンス）。物の鍵は出てこない —
  扉（木戸）は door の promise の住人に頼まれた数の薬草を持って話しかけると開く。
  鍵アイテム・インベントリを足さない。
- **盤面のデータは全部 MapDoc**（assets/rpg.map.json）: タイルの rows・住人と 1 行・
  扉と約束・薬草と灯りの配置・goal。歩ける/ぶつかる/開く/クリアの規則はコード（World）。
- **操作は「歩く」と「話す（決定）」だけ**: ←→↑↓（WASD 可）と Z / Enter / Space。
  それ以外の操作を足さない。
- **戦いは 1 対 1 のコマンド式・1 種類だけ**（assets/rpg.battle.json）。歩数で出会い、
  「たたかう / にげる」を選ぶ。**乱数は持ち込まない** — 何歩めで出会うかも、一撃の重さも
  Doc の数から決まる（決定的なので bake の絵もテストの期待値も揺れない。難しさの調整は
  Doc 側の数で足りる）。**レベル・経験値・仲間・呪文・道具・複数の魔物は足さない** —
  亜種の決め打ちになる。
- **セーブ・複数マップは持ち込まない**。
- **プレイヤーは死なない・詰まない**: goal は置いた薬草より多くを求めない（World.goalOf が
  clamp）。壊れた Doc でも fail-open で必ず起動し、クリアから表紙へ必ず帰れる。
- 盤のマス勘定は Grid / Dir4、キーは InputMap、ふきだしの状態と文字送りは
  UiDialog / UiTypewriter / RichText を使う。自前のタイル座標計算・文字折りを書かない。
- 薬草を拾うたび、里の灯りがひとつ点く（lampsLit は picked からの導出。演出であって
  ルールではないのでテストしない）。
- **倒れても詰まない**: 体力が尽きたら入口へ戻って体力が満ちる（ゲームオーバーで
  進行を失わせない）。「にげる」は必ず成功する。

## この画面の画風

**「霧の出た夕暮れの段々畑の里」。** 空も土も紫みを帯びて沈み、暖かいのは灯りだけ。

- 色は 3 つ: 暮れた紫 / 土の茶 / 灯りの橙。
- やらないこと: 真っ黒と純白を使わない（霧の中なので、いちばん暗い所も明るい所も濁らせる）。
- 画面は 2 つ（里 / 戦い）で、層の並びは `src/View.flix` の頭に書いてある。
  戦いの背景は縦のグラデ + 上下が透ける霧の帯（`Render.gradPolygon`）で作る —
  四角い帯を重ねると縁が立って「帯を貼った」ように見えるため。
- ドット絵は 16×16・等倍（タイル 20px の中に収まる）。主人公は下/上/横の 3 面を持ち、
  左向きは右向きの左右反転で済ませる（絵を増やさない）。魔物は戦いのときだけ 5 倍で描く。
- 意味色キー（skin / hair / foe …）の実色は `ThemeDoc.resolver` が基準色から導く。
  色票（rpg.theme.json）に足すのは「そこから導けない色」だけ。キーを足したら
  `make palette` で写しを作り直す（`make lint-palette` が食い違いを見つける）。
- **これは数ある画風の 1 つでしかない。** このテンプレから作るゲームは、画風を自分で決めて
  ここに書き直し、View の層構成ごと作り替えてよい（決め方は `.claude/skills/visual-dict`）。
