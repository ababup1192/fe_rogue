# このゲーム固有の設計原則

縦スクロール・シューティングのテンプレート。原始的なシューティングに、読んで学べる最小限を
足した骨格 — 連射レート（fireInterval）・波（文字格子で配置）・弾↔敵/敵↔自機の当たり判定・
撃破の控えめな爆発演出・流れる星の背景。

- **規則はコード、数値・色・配置は Doc**（エッセンス）。撃つ・当たる・降りる・全滅で次の波へ の
  規則は `src/World.flix`（純粋）にある。JSON に if 文を書き始めたら境界を越えた合図。
  調整する数値は `assets/shooter.rules.json`、色は `assets/shooter.theme.json`、
  敵の並びは `assets/shooter.waves.json`。
- **敵の配置は文字格子（rows）**: 1 波 = 1 つの文字格子（`WavesDoc`）。'.'/空白 = 空き、
  それ以外の文字 = 敵 1 体（rpg のマップ rows と同じ発想）。「どの文字が敵か」の判断は
  `WavesDoc.isEnemy` 1 か所だけ。格子 → 敵の初期位置への写しは `World.spawnWave`。
- **当たり判定は素直な総当たり**: 敵は 1 波ぶんと少ないので「弾 × 敵」の二重ループで判定する
  （空間分割などは持ち込まない）。中心距離で重なりを見る（`World.overlaps`）。
- **連射レートはルール**: 発射は Space 押しっぱなし。実際に撃てるのは `fireInterval` ごと
  （`World.tryFire` の fireCooldown）。ここはテストする（演出ではなくルール）。
- **波の進行はルール**: 生存敵が 0 になったら全滅 → 次の波へ、無ければ CLEAR。
  被弾は「生きた敵が自機の高さ（playerY）まで降りてきたら GAME OVER」で素直に判定する。
- **足さないもの**: 残機（1 発被弾で GameOver）・敵の弾/反撃・敵の横移動や AI・パワーアップ・
  ボス・スクロールするステージ。この骨格に亜種の決め打ちを足さない（足すなら別テンプレ）。
- **プレイヤーは詰まない・壊れない**: 壊れた Doc でも fail-open で必ず起動し、
  Clear/GameOver から Space で必ず Title へ戻れる。View も敵が空・Doc 既定で必ず何か描く。
- 描画はエンジンの `Render`（`box`/`boxAt`/`polygon`/`textTinted`/`fade`/`glowAt`）を使い、
  幾何・文字折り・パーティクルを自前で書かない。撃破の爆発は `Render.glowAt`
  （閉形式で安全）に任せ、粒子系を手書きしない。

## テストの当てどころ（ルールだけ）

- 発射（`fireInterval` が空いていれば撃てる・クールダウン中は撃てない）。
- 弾の移動と盤外での消滅（上端を越えた弾が消える）。
- 当たり判定（弾が敵に重なると撃破・加点・弾が消える / 離れた弾は当たらない）。
- 被弾（生きた敵が playerY まで降りたら GAME OVER / 撃破済みの敵は脅威でない）。
- 波の進行（全滅で次の波・ボーナスは `waveClearBonus` / 最後の波の全滅で CLEAR）。
- 波の生成（格子の敵マス数と生成される敵の数が一致）・場面の決定（Title→Playing・GameOver→Title）。
- 爆発・星・自機の三角の見た目はテストしない（golden / 目視の担当）。
